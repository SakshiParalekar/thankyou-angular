# Thank You Page - Angular Assignment

This is a simple Angular project for an internship assignment.  
It displays a **Thank You page** with:

- Message: "Thank You! Your submission has been received successfully."
- Buttons:
  - **Send Email to Recruiter** (opens default email client)
  - **Go Back**
- Styled with CSS for a professional look

---

## How to run

1. Install dependencies
2. Run the app
3. Open in browser: `http://localhost:4200`
